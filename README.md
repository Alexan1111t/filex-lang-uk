# Українська локалізація для filex

Повний український мовний пакет для [filex](https://github.com/BRF-Tech/filex) — самостійно розгорнутого файлового менеджера з вебінтерфейсом.

Пакет перекладає файловий менеджер, адміністративну панель, налаштування, публічні сторінки, сповіщення, електронні листи та серверні повідомлення.

## Стан перекладу

- Мова: українська (`uk`)
- Сумісність каталогу: filex `0.61.2`
- Перекладено: 7 518 із 7 518 рядків (100%)

> Переклад створено автоматично та перевірено офіційним валідатором filex. Формулювання можуть потребувати подальшого редагування носіями української мови. Виправлення через Issues та Pull Requests вітаються.

## Встановлення з GitHub

1. Увійдіть у filex як адміністратор.
2. Відкрийте **Admin → Plugins → Apps**.
3. Натисніть **Install an app**.
4. Виберіть **GitHub repository**.
5. У полі **Repository** введіть:

   ```text
   Alexan1111t/filex-lang-uk
   ```

6. У полі **Ref** введіть `main` або залиште його порожнім.
7. Натисніть **Review permissions**, перевірте інформацію та завершіть встановлення.

Мовний пакет не містить виконуваного модуля та не запитує дозволів на доступ до файлів.

## Встановлення з файлу

1. Завантажте `filex-app.json` із цього репозиторію.
2. У filex відкрийте **Admin → Plugins → Apps → Install an app**.
3. Виберіть **Upload files**.
4. Завантажте `filex-app.json` як файл маніфесту.
5. Поля модуля, бінарного файлу та інтерфейсного пакета залиште порожніми.
6. Перегляньте інформацію та підтвердьте встановлення.

## Увімкнення української мови

Після встановлення відкрийте:

```text
Settings → Preferences → Language → Українська
```

Мову можна вибирати окремо для кожного облікового запису. Вона також доступна на публічних сторінках спільного доступу.

## Оновлення

Якщо пакет установлено з GitHub, filex періодично перевіряє гілку `main`. Коли в маніфесті з’явиться новіша версія, у списку застосунків буде запропоновано оновлення.

Оновлення не встановлюється автоматично: адміністратор має переглянути його та підтвердити.

Якщо пакет установлено з локального файлу, завантажте новий `filex-app.json` і скористайтеся дією **Upgrade** біля встановленого пакета.

## Розробка та перевірка

Для роботи потрібен Node.js 18 або новіший.

```bash
npm install
node scripts/pack.mjs build
node scripts/validate.mjs filex-app.json
```

Файл перекладу знаходиться тут:

```text
translations/uk.json
```

Перед публікацією змін:

1. Відредагуйте `translations/uk.json`.
2. Збільште значення `version` у `filex-app.json`.
3. Перебудуйте маніфест.
4. Запустіть валідатор.
5. Надішліть зміни до гілки `main`.

## Оновлення каталогу рядків

Після виходу нової версії filex синхронізуйте каталог із сервером:

```bash
node scripts/pack.mjs sync --from https://your-filex.example.com
```

Або з конкретного релізу:

```bash
node scripts/pack.mjs sync --from v0.61.2
```

Після синхронізації перекладіть нові та змінені рядки, перебудуйте пакет і повторно запустіть перевірку.

## Видалення

Відкрийте **Admin → Plugins → Apps**, знайдіть український мовний пакет і виберіть **Remove**. Користувачі, які вибрали українську, автоматично перейдуть на наступну доступну мову.
